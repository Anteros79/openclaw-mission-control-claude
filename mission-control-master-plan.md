# PhoenixClaw Mission Control Master Task Ledger

## Ledger Rules
- Canonical status values: `proposed`, `ready`, `in_progress`, `blocked`, `done`, `deferred`
- Stable fields: `ID | Status | Depends On | EARS Requirement | Verification | Evidence | Last Updated`
- EARS-only requirement forms:
  - `The system shall...`
  - `When ... the system shall...`
  - `While ... the system shall...`
  - `Where ... the system shall...`
  - `If ... then the system shall...`
- Atomization rule: if a requirement contains multiple independently verifiable behaviors, split it into separate task IDs.
